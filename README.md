# KousieLegacy — SEO & Web Designer Portfolio

## Files
- `index.html`: fully expanded, readable HTML for every portfolio section.
- `style.css`: responsive styles, including portrait and project image containers.
- `script.js`: mobile navigation, reveal animations, project filters, image fallbacks and contact form.
- `images/`: place your own photos and project screenshots here.

## Add your images
Place your photo at `images/profile.jpg` and your project screenshots at `images/project-1.jpg`, `images/project-2.jpg`, and `images/project-3.jpg`.

If your files use `.png` or `.webp`, update the corresponding `src` in `index.html`.
Images are cropped with CSS `object-fit: cover`; change it to `contain` if you need full screenshots visible.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Connect contact form
In `script.js`, change `CONTACT_EMAIL` from `you@example.com` to your real email address. Publish the site, submit a test message, and activate FormSubmit using the verification email. Test again after activation. FormSubmit is an external service; check its terms and spam protection options before production use. A static website alone cannot deliver email without an external service or backend.

## Personalize
Replace the sample text, placeholder project descriptions, education entries, and social media links with your actual details. Do not claim unverified project outcomes.
